# 👑 Tiny King — Defesa do Reino

Réplica jogável do gameplay prometido pelos famosos anúncios "falsos" de jogos mobile
(estilo Kingshot/Thronefall): construa defesas de dia, sobreviva às hordas à noite.

- 🎮 **Jogo:** HTML5/Canvas puro, mobile-first (toque), arte e sons 100% originais/procedurais
- 📱 **Distribuição:** APK Android instalável (empacotado com Capacitor)
- 🗺️ **Planejamento:** ver [ROADMAP.md](ROADMAP.md) — o documento-mestre com tudo que foi feito e o que falta

## Rodar localmente

```bash
python3 -m http.server 8123
# abrir http://localhost:8123
```

> ⚠️ Projeto em desenvolvimento — `game.js` ainda está incompleto (ver Fase 1 do roadmap).
